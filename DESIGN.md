# DESIGN.md — Визуальная система и дизайн-токены `crownvetch`

## 1. Концепция и эстетика

Визуальный язык объединяет атмосферу тёмной фотолаборатории (`DARKROOM`) и ботанического гербария (`HERBARIUM`): глубокий угольно-зелёный фон, мягкие пастельные акценты проявочной комнаты и чёткая типографическая иерархия.

## 2. Цветовая палитра (`src/styles/tokens.css` и `src/data/palette.json`)

| Токен | HEX | Назначение |
| :--- | :--- | :--- |
| `--bg-void` | `#0E1110` | Основной фон страниц и подложек |
| `--bg-surface` | `#171C1A` | Карточки, контейнеры, панели модулей |
| `--bg-surface-elevated` | `#1F2623` | Активные блоки сцен, всплывающие панели |
| `--accent-sage` | `#A8D5BA` | Основной акцент (пастельный вязель), активные ссылки, кнопки |
| `--accent-amber` | `#F2DC9B` | Вторичный акцент (тёплый фонарь), метки глав и спикеров |
| `--accent-violet` | `#C5B4E3` | Мистический акцент (негатив), статусы модулей |
| `--text-primary` | `#ECEEEB` | Основной текст («архивная бумага») |
| `--text-secondary` | `#B4BCB7` | Описания и второстепенный текст |

## 3. Сетка и адаптивность

- Максимальная ширина основного контейнера: `1120px` с боковыми полями `20px`.
- Все сетки (`palette-grid`, `modules-grid`) построены на CSS Grid (`repeat(auto-fill, minmax(..., 1fr))`) и корректно перестраиваются под мобильную ширину `390px` без горизонтального скролла.
- Интерактивные элементы (карточки палитры, кнопки выбора в квесте) имеют явные состояния `:hover` и доступные `aria-label`.
